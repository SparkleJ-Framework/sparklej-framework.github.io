Sparkle Core Module

The core module contains the fundamental functionality required for all Sparkle applications. It provides the essential infrastructure for rendering, audio playback, event propagation, and collision detection.

Key components include:

  • Audio & graphics management via the AudioManager and GraphicsManager components.
  • Robust event dispatching and handling through the EventDispatcher component and the Event class hierarchy.
  • A dedicated 2D hitbox system for precise collision checking, exposed via the Hitbox2D API.
